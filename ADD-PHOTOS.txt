HOW TO ADD PHOTOS TO THE R&G HOMES SITE
=======================================

1. Resize the photo first: about 1000 pixels wide, under 200 KB.
   Use simple lowercase file names with no spaces, e.g. kitchen2.jpg

2. On GitHub, open the  images/full  folder, click Add file > Upload files,
   and upload the photo.

3. Open  photos.js  and click the pencil icon.
   Copy one line, paste it above the closing  ];  and change it:

     { f: "kitchen2.jpg", t: "Marble Kitchen Island", c: "kit" },

   f = the file name you uploaded
   t = the caption
   c = living / dining / bed / kit   (sets which filter button it appears under)
   Add  s: true  to also put it in the homepage slideshow:

     { f: "kitchen2.jpg", t: "Marble Kitchen Island", c: "kit", s: true },

4. Click Commit changes. The site updates in 1-2 minutes.

To add a new category button (e.g. Wardrobes), add a line to CATEGORIES at the
top of photos.js:   wardrobe: "Wardrobes",
then use  c: "wardrobe"  on the photos.

To remove a photo, delete its line in photos.js.
Keep the commas at the end of each line except the last one.
